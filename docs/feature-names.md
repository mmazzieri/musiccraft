# Feature names

Checked against [standards/naming.md](https://github.com/storytold/craft-contrib/blob/main/standards/naming.md)
on 2026-11-24. Labels are ordinary descriptive words. The trademark registers were not searched.

| Our label | Why |
| --- | --- |
| Play queue | Descriptive. *Up Next* is another product's label and is not used. |
| Song Information | Descriptive. *Get Info* is not used. |
| Service in use | Descriptive. |
| Compact Player | Descriptive. |
| Smart Lists, Smart Playlist | Used descriptively by unrelated players (Navidrome and Plex, among others). |
| Column Browser | Describes what it is. |
| Recently Added, Recently Played, Most Played, Loved Songs | Descriptive. |
| Import Library File | Descriptive. iTunes and the Music app are named only in the documentation, to say which file it reads. |

Names of services (Spotify, Spotify Soloist, TIDAL, Apple Music, Deezer, YouTube Music, Amazon Music, Navidrome, Gonic, Airsonic, Subsonic, Radio Browser) appear
only to say what MusicCraft works with, or does not work with.
