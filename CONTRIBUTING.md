# Contributing

Issues and pull requests are welcome. [AGENTS.md](AGENTS.md) has the rules, for people and for coding
agents: they are those of the Craft app family, with the specifics of this repository at the end.

Run `cargo xtask ci` before opening a pull request. Building needs Rust 1.95 or newer; on Linux also
the ALSA headers (`libasound2-dev` or `alsa-lib-devel`).
